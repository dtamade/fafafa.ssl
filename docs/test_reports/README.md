# Test Reports Directory (Historical Verification Records)

`docs/test_reports/**` stores generated verification reports and delivery evidence.

## Purpose

- Keep command output snapshots and validation artifacts for auditability.
- Retain historical evidence across phases and waves.

## Active Backlog Boundary

- Files in this directory are **historical verification records**, not active design/spec documents.
- Active docs noise scans should exclude this directory by default.
