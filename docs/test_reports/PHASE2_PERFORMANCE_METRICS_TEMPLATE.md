## 4. 回归判定规则（Draft）

- **吞吐类指标**：下降超过 **15%** 记为回归候选。
- **时延类指标**：上升超过 **20%** 记为回归候选。
- **功能门禁**：若同轮 P2 功能回归失败，则性能结论不予采纳。

> 说明：阈值为草案，可在 B6/B7 阶段按实测波动收敛。
