## OpenSSL 3.x 兼容性分析

### API 变化总结

在验证过程中，发现以下 OpenSSL 1.x 函数在 OpenSSL 3.x 中已移除或弃用：

**P2 模块不可用函数** (7个):
- CMS: `CMS_get1_Receipt`, `CMS_set1_signer_cert`
- TS: `TS_REQ_d2i_bio`
- OCSP: `OCSP_REQ_CTX_i2d`, `OCSP_REQ_CTX_nbio`, `OCSP_REQ_CTX_nbio_d2i`
- SRP: `SRP_user_pwd_set_salt`

**P3 模块不可用函数** (6个):
- SRP: `SRP_user_pwd_set_salt`, `SRP_user_pwd_set_verifier`, `SRP_user_pwd_get0_salt`,
  `SRP_user_pwd_get0_verifier`, `SRP_user_pwd_get0_name`, `SRP_get_1_by_id`

**P4 模块不可用函数** (3个):
- Engine: `ENGINE_set_id`, `ENGINE_ctrl`, `ENGINE_load_public_key`

### 弃用状态

| 模块类别 | 弃用模块 | 建议 |
|---------|---------|------|
| P2 | 无 | 全部推荐使用 |
| P3 | SRP, Comp | 考虑迁移到现代替代方案 |
| P4 | Engine | 迁移到 Provider API |

## 测试方法论

### 测试框架

所有测试使用统一的测试框架结构：

```pascal
procedure StartTest(const TestName: string);
procedure PassTest;
procedure FailTest(const Reason: string);
```

### 测试类型

1. **函数加载测试**: 验证所有 API 函数是否成功从 OpenSSL 库加载
2. **常量定义测试**: 验证所有常量值是否正确定义
3. **生命周期测试**: 验证对象创建和释放是否正常
4. **功能测试**: 验证核心功能是否按预期工作
5. **综合测试**: 验证完整工作流程和复杂场景

### 验证流程

1. 编译测试程序（使用 Free Pascal Compiler 3.3.1）
2. 运行测试并收集结果
3. 分析失败原因
4. 使用 `nm -D` 验证函数是否存在于 OpenSSL 库中
5. 修复可修复的问题
6. 记录 OpenSSL 3.x 的已知限制

## 自动化测试基础设施

### 1. 模块测试自动化脚本

**文件**: `scripts/run_all_module_tests.sh`

**功能**:
- 自动编译所有模块测试（已优化编译选项，移除导致链接错误的调试标志）
- 运行测试并捕获输出
- 生成详细的测试报告
- 支持选择性模块测试
- 超时保护（60秒/测试，已从30秒增加）
- 失败时可选择立即停止
- **智能部分通过检测**：自动识别并报告部分通过的测试（如 Engine 7/10）

**使用方法**:
```bash
# 运行所有测试
./scripts/run_all_module_tests.sh

# 详细输出模式
./scripts/run_all_module_tests.sh --verbose

# 测试特定模块
./scripts/run_all_module_tests.sh --modules "PKCS7,CMS,Store"

# 遇到失败立即停止
./scripts/run_all_module_tests.sh --stop-on-fail
```

### 2. 持续测试监控脚本

**文件**: `scripts/continuous_test_monitor.sh`

**功能**:
- 循环运行模块测试
- 跟踪测试结果趋势
- 生成历史报告和趋势分析
- 失败时发送警报
- 支持配置测试间隔和最大运行次数

**使用方法**:
```bash
# 每小时运行一次测试
./scripts/continuous_test_monitor.sh

# 自定义测试间隔（秒）
./scripts/continuous_test_monitor.sh --interval 1800

# 限制运行次数
./scripts/continuous_test_monitor.sh --max-runs 10

# 启用失败警报
./scripts/continuous_test_monitor.sh --alert-on-fail
```

**监控输出**:
- 实时测试结果
- 历史数据（CSV 格式）
- 趋势报告（每5次运行生成）
- 平均通过率统计
- 质量趋势分析
