### 3.2 弃用 API 情况

以下 API 已标记为弃用，但仍在内部使用以保持向后兼容：

```pascal

ISSLContext.SetServerName  → 应使用 ISSLClientConnection.SetServerName
```

**状态**: 这是有意的设计选择，为旧代码提供迁移路径。
