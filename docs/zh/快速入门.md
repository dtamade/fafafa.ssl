## 什么是 fafafa.ssl

fafafa.ssl 是一个统一的 SSL/TLS 库，为 Free Pascal 和 Delphi 提供简单易用的 HTTPS 通信接口。

### 主要特性

- ✅ **统一接口**：同时支持 OpenSSL 和 Windows Schannel
- ✅ **简单易用**：几行代码即可实现 HTTPS 通信
- ✅ **生产就绪**：完整的错误处理和日志系统
- ✅ **跨平台**：支持 Windows、Linux、macOS
- ✅ **全功能**：支持客户端/服务器、双向TLS、会话复用等

## 系统要求

### 必需
- Free Pascal 3.2.0+ 或 Delphi 10.x+

## 安装

### 方法一：使用 Git（推荐）

```bash
git clone https://github.com/你的用户名/fafafa.ssl.git
cd fafafa.ssl
```

### 方法二：下载源码

1. 访问 [GitHub Releases](https://github.com/你的用户名/fafafa.ssl/releases)
2. 下载最新版本
3. 解压到项目目录

### 配置编译器路径

#### Lazarus

1. 打开 `fafafa_ssl.lpk`
2. 点击 "Use" → "Install"
3. 重新编译 IDE

#### Free Pascal (命令行)

```bash
# 添加到搜索路径
export FPC_PATH=/path/to/fafafa.ssl/src
fpc -Fu$FPC_PATH your_program.pas
```

#### Delphi

1. 工具 → 选项 → Language → Delphi → Library
2. 添加 `src` 目录到 Library Path

## 第一个HTTPS请求

### 完整示例代码

创建文件 `my_first_https.pas`：

> 注意：`fafafa.ssl` 只负责 TLS。
> 下面示例假设 `LSocket` 已经是你自己建立并连接到 `www.google.com:443` 的 TCP socket。

```pascal
program my_first_https;

{$mode objfpc}{$H+}

uses
  SysUtils, fafafa.ssl, fafafa.ssl.context.builder;

var
  LContext: ISSLContext;
  LTLS: TSSLConnector;
  LStream: TSSLStream;
  LSocket: THandle;  // 这里放你自己建立并连接好的 TCP socket
  LRequest, LResponse: string;
  LBuffer: array[0..8191] of Byte;
  LBytesRead: Integer;

begin
  try
    // 1. 创建 SSL 上下文
    WriteLn('创建SSL上下文...');
    LContext := TSSLContextBuilder.Create
      .WithTLS12And13
      .WithVerifyPeer
      .WithSystemRoots
      .BuildClient;
    
    // 2. 建立 TLS
    WriteLn('建立TLS连接...');
    LTLS := TSSLConnector.FromContext(LContext);
    LStream := LTLS.ConnectSocket(LSocket, 'www.google.com');

    try
      WriteLn('TLS连接成功！');

      // 3. 发送 HTTP 请求
      LRequest := 'GET / HTTP/1.1'#13#10 +
                  'Host: www.google.com'#13#10 +
                  'User-Agent: fafafa.ssl/1.0'#13#10 +
                  'Accept: */*'#13#10 +
                  'Connection: close'#13#10#13#10;

      WriteLn('发送请求...');
      LStream.Write(LRequest[1], Length(LRequest));

      // 4. 读取响应
      WriteLn('读取响应...');
      LBytesRead := LStream.Read(LBuffer[0], Length(LBuffer));
      SetLength(LResponse, LBytesRead);
      Move(LBuffer[0], LResponse[1], LBytesRead);

      // 5. 显示结果
      WriteLn('收到响应 (', LBytesRead, ' 字节):');
      WriteLn(Copy(LResponse, 1, 200), '...');

      WriteLn;
      WriteLn('成功！');
    finally
      LStream.Free;
    end;
    
  except
    on E: ESSLException do
      WriteLn('SSL错误: ', E.Message);
    on E: Exception do
      WriteLn('错误: ', E.Message);
  end;
end.
```

如果你只想最快拿到 HTTPS 响应，也可以直接使用 `TSimpleHTTPSClient.Get(...)`；
如果你想显式控制 TLS context / stream，再继续沿用这里的 `TSSLContextBuilder` + `TSSLConnector` 路径。

### 编译运行

```bash
# Free Pascal
fpc my_first_https.pas
./my_first_https

# 或使用 Lazarus
# 打开项目 → 运行 (F9)
```

### 预期输出

```
创建SSL上下文...
创建连接...
连接到 www.google.com:443...
连接成功！
发送请求...
读取响应...

HTTP/1.1 200 OK
Date: Wed, 05 Nov 2025 12:00:00 GMT
...

成功！
```

## 常见问题

### Q: 编译时找不到 OpenSSL

**A:** 确保已安装 OpenSSL 开发包：

```bash
# Ubuntu/Debian
sudo apt-get install libssl-dev

# CentOS/RHEL
sudo yum install openssl-devel

# macOS
brew install openssl
```

### Q: 连接失败

**A:** 检查：
1. 网络连接是否正常
2. 目标服务器是否可访问
3. 端口是否正确（HTTPS默认443）
4. 防火墙设置

### Q: 证书验证失败

**A:** 对于测试，可以禁用验证：

```pascal
LContext.SetVerifyMode([]);  // 当前 direct-context no-verify 入口；builder 请改用 WithVerifyNone
```

⚠️ **警告**：生产环境务必启用证书验证！

### Q: 如何启用详细日志？

**A:** 使用日志系统：

```pascal
uses
  fafafa.ssl.logger;

var
  LLogger: ILogger;
begin
  LLogger := TConsoleLogger.Create('app.log', llDebug);
  // 你的代码
end;
```
