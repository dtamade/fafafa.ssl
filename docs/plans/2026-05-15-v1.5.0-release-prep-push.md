# v1.5.0 Release-Prep Push Plan

## Goal

从当前已经 green 的 release-control 状态出发，形成一个可推送到 `origin` 的 `v1.5.0` 预备分支，给后续 merge / tag 审批提供明确的远端 handoff 点。

## Architecture

- 当前技术基线：`release/v1.5.0-prep-2026-05-15`，派生自 `5f23652`
- 当前控制面：`docs/ROADMAP.md` -> `docs/plans/2026-05-12-release-v1.5.0-formalization.md` -> `docs/test_reports/RELEASE_READINESS_V1.5.0.md` -> `.github/README.md`
- 本批只允许修改：
  - release-prep 计划文档
  - handoff 文档
  - 根 working-memory 文件
- 本批不允许：
  - 改 `origin/master`
  - 创建 `v1.5.0` tag
  - 发布 GitHub Release
  - 假装 Windows runtime 证据已经补齐

## Task 1: Metadata And Handoff Draft

Write:

- current release-prep goal / queue / stop condition
- current branch choice and push boundary
- deferred Windows/WinSSL statement
- handoff doc draft with placeholders for final commit / push status

## Task 2: Verification

Run from repo root:

```bash
bash tests/scripts/test_release_control_entrypoint_convergence_contract.sh
bash tests/scripts/test_active_roadmap_references_contract.sh
bash tests/scripts/test_platform_support_guidance_convergence_contract.sh
bash tests/scripts/test_active_docs_historical_reference_labels_contract.sh
bash tests/scripts/test_release_workflow_v1_5_0_contract.sh
python3 scripts/compile_all_modules.py
bash scripts/run_minimal_ci_gate.sh --fast-local
bash scripts/run_freepascal_tls13_completeness_gate.sh --fast-local --run-id release_prep_20260515
python3 scripts/check_code_style.py src
bash scripts/run_phase2_performance_baseline.sh --dry-run --fast-local
git diff --check
git status --short
```

Expected:

- all contracts remain green
- release-control gates remain green on the release-prep branch
- no repo-tracked drift remains after verification

## Task 3: Review, Commit, Push

- summarize a short review conclusion before commit
- commit only the metadata / handoff batch
- push `release/v1.5.0-prep-2026-05-15` to `origin`
- if the remote branch name is unexpectedly occupied during push, fallback to `release/v1.5.0-prep-2026-05-15-v2`

## Task 4: Final Handoff

Update the handoff doc with:

- branch name
- final HEAD commit
- exact verification set and results
- explicit `no-merge / no-tag` boundary
- `Windows runtime evidence deferred` note
