# Plans Directory (Historical Execution Records)

`docs/plans/**` stores implementation plans created during iterative execution.

## Purpose

- Preserve decision context and execution traces for historical review.
- Provide reproducible command history for completed batches.

## Active Backlog Boundary

- Files in this directory are **historical records**, not the active source of truth for current queue management.
- Current execution/治理入口请先看 `../PLANS_CURRENT_INDEX.md`。
- 当前月度汇总请看 `2026-03-current-summary.md`。
- Active docs noise scans should exclude this directory by default.

## Recommended Use

- Read for background and traceability.
- Do not treat TODO/TBD text in old plans as current execution commitments.
